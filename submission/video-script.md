# Сценарий видео (до 3:00)

Видео собирается **без записи экрана**: фильмы дней снимает сама сцена кадр за кадром (`tools/make-video.ts`), экраны ввода — стоп-кадрами приложения. Звук — песни дней; голоса нет, только титры.

| Время | Кадр | Титр | Откуда |
|---|---|---|---|
| 0:00–0:10 | закрытая книга на столе под лампой, медленный наезд | «Фотография помнит, как день выглядел.» → «Мы хотим вернуть, как он ощущался.» | первые 10 с фильма дня 1 (`--from 0 --to 10`) |
| 0:10–0:32 | ввод: пустая страница с заготовкой → текст рукописью → три полароида на правой странице → кассета «100 bpm» → уголок «Собрать» со сменой «читаю запись… смотрю фото…» | «Пара предложений. Фото. Песня дня.» | 5 стоп-кадров по 4–5 с, лёгкий зум (`zoompan`) |
| 0:32–1:30 | **фильм дня 1 целиком**: человечек вылезает, вытягивает слова, слова → кубики → наклейки; полароид проявляется; облёт вокруг человечка с какао; иней по краям и тёплый свет (противоречие «холодно, но тепло»); книга закрывается, название на обложке | без титров, только песня | `make-video --day 0 --photos 3 --song …` |

| 2:50–3:00 | книга встаёт на полку к другим дням | «Дневник-книга · REC GENESIS · ArtTech» + команда | последние 6 с фильма дня 1 (`--from 54`) |

## Сборка

```bash
# фильмы (нужен npm run dev на 5183; кадры → assets/_raw/snaps, ролики → submission/video)
npx tsx tools/make-video.ts --day 0 --photos 3 --song demo/day1.mp3 --out submission/video/day1.mp4
npx tsx tools/make-video.ts --day 1 --from 15 --to 30 --song demo/day2.mp3 --out submission/video/day2_part.mp4
npx tsx tools/make-video.ts --day 2 --from 10 --to 25 --song demo/day3.mp3 --out submission/video/day3_part.mp4

# стоп-кадр в ролик 5 с с лёгким зумом
ffmpeg -loop 1 -i still.png -vf "zoompan=z='min(zoom+0.0008,1.06)':d=120:s=1920x1080,fps=24" -t 5 -pix_fmt yuv420p still.mp4

# склейка частей (одинаковые размер, fps и кодек)
printf "file '%s'\n" intro.mp4 input.mp4 day1.mp4 why.mp4 day2_part.mp4 day3_part.mp4 library.mp4 scheme.mp4 outro.mp4 > parts.txt
ffmpeg -f concat -safe 0 -i parts.txt -c:v libx264 -pix_fmt yuv420p -c:a aac final.mp4
```

Титры кладём фильтром `drawtext` (шрифт Caveat) или в любом монтажном редакторе поверх готовых частей.

Проверка: длительность `ffprobe -show_entries format=duration final.mp4` меньше 180 с; ролик открывается по ссылке без входа.
