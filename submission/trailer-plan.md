# Трейлер «Дневник-книга» — план (≈2:00, без голоса, только субтитры)

Цель: жюри за 2 минуты понимает идею, видит, как запись дня становится фильмом, и запоминает три вещи: **рассказ дня**, **человечек проживает день**, **всё из своих слов, фото и песни**.

## Формат

- 1920×1080, 24 к/с, H.264 (mp4), звук AAC; длина 1:55–2:10; файл до 80 МБ.
- Субтитры — вшитые титры (ffmpeg `drawtext`), шрифт Caveat из проекта (`assets` или `public`, OFL), белые с мягкой тенью; внизу по центру; на экране 2.5–4 с, появление и уход 0.3 с.
- Голоса нет. Музыка — **своя**, без чужих песен: короткий тёплый трек, синтезированный кодом (Python + numpy → wav: аккорды и мелодия «музыкальная шкатулка», 90–100 bpm, 2:10). Звук сцены (щелчки шагов, «чпок» предметов) — поверх, тише музыки.
- Источники кадров: `tools/make-video.ts` (фильм дня кадр за кадром из самой сцены, без записи экрана) и стоп-кадры приложения из встроенного браузера. Монтаж — ffmpeg (`concat`, `xfade` 0.4 с, `zoompan` для стоп-кадров).
- Готовый файл: `submission/video/trailer.mp4`, копия для ссылки без входа — `public/trailer.mp4`, тогда она открывается по адресу https://memory-book-mauve.vercel.app/trailer.mp4.

## Шаги

1. Кадры фильмов: `npx tsx tools/make-video.ts` (см. шапку файла) по двум дням — с фото (`photos_test`, тестовые фото сгенерированы ИИ) и `story_bored`; без песни (музыка накладывается при монтаже). Если демо-день нужен через `--day N`, добавить дни в `src/timeline/samples` или передать текст — по месту.
2. Стоп-кадры ввода с живого сайта: первый экран, запись с текстом, фото, кассета с 3 песнями, сургуч, «Почему так», полка. 1920×1080, без отладочных надписей.
3. Музыка: синтез своего трека скриптом (сохранить скрипт в `tools/`), нормализовать до −16 LUFS.
4. Монтаж ffmpeg по раскадровке, субтитры `drawtext`, плавные переходы, финальный титр.
5. Проверка: длина ≤ 2:10, субтитры читаются на телефоне, нет чужой музыки и чужих фото людей (только сгенерированные ИИ тестовые), файл открывается в браузере.
6. Положить в `public/trailer.mp4` (если ≤ 80 МБ) и в `submission/video/`.
