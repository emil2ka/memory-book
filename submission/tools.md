# Библиотеки, API и AI-инструменты

Всё, что сделано с помощью AI, названо прямо.

## Библиотеки (в приложении)

| Что | Версия | Для чего | Лицензия |
|---|---|---|---|
| three.js | 0.187 | 3D-сцена: комната, стол, книга, свет, тени, пиксельный слой для жителей | MIT |
| React, React DOM | 19.3 | интерфейс поверх сцены | MIT |
| fflate | 0.8 | экспорт дня ZIP-папкой | MIT |
| @anthropic-ai/sdk | 1.12 | вызов Claude API на сервере (функции Vercel) | Apache-2.0 |

## API и сервисы

| Что | Для чего | Условия |
|---|---|---|
| **Claude API, модель Claude Haiku 5.5** (`claude-haiku-5-5`) | режиссёр (сценарий, рассказ, эмоции), сценограф, карточка фото, подбор песни, мастер моделей | ключ только на сервере, в переменной окружения |
| **Supabase** — Auth, Postgres, Storage | аккаунт (почта и пароль), дни в таблице `days`, фото в приватном хранилище `photos` (папка пользователя); правила RLS: каждый видит только своё (`supabase/schema.sql`) | бесплатный тариф; в сборке только адрес и публичный ключ |
| **YouTube IFrame Player API** | песня дня играет официальным встроенным плеером; часы фильма — от плеера | условия YouTube API; файлов песен у нас нет |
| **YouTube oEmbed** | проверка роликов для списка песен: ролик существует, его можно встраивать, название совпадает (`eval/verify-yt.ts`); название песни по ссылке | публичный эндпоинт без ключа |
| **Vercel** | хостинг сайта и серверных функций (Build Output API) | бесплатный тариф |

## AI-инструменты

| Что | Для чего |
|---|---|
| **Claude Design** (Anthropic; модели Claude Opus 5.5 и Claude Fable 5.2) | 3D-модели мира: комната, стол, книга, лампа, кассетник, полка; скелет и клипы движений людей (GLB) |
| **Claude** (Claude Code) | код приложения; объёмные предметы библиотеки (171) собраны из простых фигур по правилам стиля; анимации человечка; проверенный список 96 песен |
| **Claude Haiku 5.5** во время работы приложения | режиссёр: сценарий, строки рассказа, эмоция и действие на каждый момент; сценограф; карточка фото; 3 песни под запись; мастер моделей |
| **Claude Haiku 5.5 с картинкой** («проверка глазами») | смотрит на построенный предмет так, как его увидит зритель; не узнал — предмет перестраивается (`tools/kit_recognize.ts`) |
| **ChatGPT** (генерация картинок) | концепт-макеты на этапе идеи; иконки и фактуры бумажного интерфейса «канцелярия»: бумага, бирки, сургуч, скотч, закладка, кассета (`assets/ui`) |
