## API

| Что | Для чего | Условия |
|---|---|---|
| **Claude API, модель Claude Haiku 5.5** (`claude-haiku-5-5`) | режиссёр: текст + фото + песня → сценарий фильма (JSON по схеме); дорисовка предмета-картинки, если слова нет в библиотеке | коммерческие условия Anthropic; ключ только на сервере, в переменной окружения; на ключе — лимит расходов |
| oEmbed (YouTube, Spotify, SoundCloud) | название и исполнитель по ссылке на песню | публичные эндпоинты, без ключа; сама песня не скачивается |

## AI-инструменты

| Что | Для чего |
|---|---|
| **Claude Design** (Anthropic; модели Claude Opus 5.5 и Claude Fable 5.2) | 3D-модели мира: комната, стол, книга, лампа, кассетник, полка; скелет и клипы движений рук и людей (GLB) |
| **Claude** (Claude Code) | код приложения; 165 объёмных предметов библиотеки собраны Claude из простых фигур по правилам стиля, 90 предметов нарисованы в SVG — ничего не взято из стоков |
| **Claude Haiku 5.5** во время работы приложения | режиссёр: сценарий каждого дня; сценограф: главный предмет, место и второй человечек для каждой фразы; мастер моделей: новый предмет для слова, которого нет в библиотеке |
| **Claude Haiku 5.5 с картинкой** («проверка глазами») | смотрит на нарисованный предмет так, как его увидит зритель, и говорит, что это; не узнал — предмет перерисовывается. Тем же способом проверена вся библиотека (`tools/kit_recognize.ts`, `eval/make-batch.ts`) |
| ChatGPT (генерация картинок) | концепт-макеты на этапе идеи и нарисованные фактуры интерфейса «канцелярия»: бумага, сургучная печать, бирка, скотч, закладка, кассета (`assets/ui`) |
