## API

| Что | Для чего | Условия |
|---|---|---|
| **Claude API, модель Claude Haiku 5.5** (`claude-haiku-5-5`) | режиссёр: текст + фото + песня → сценарий фильма (JSON по схеме); дорисовка предмета-картинки, если слова нет в библиотеке | коммерческие условия Anthropic; ключ только на сервере, в переменной окружения; на ключе — лимит расходов |
| oEmbed (YouTube, Spotify, SoundCloud) | название и исполнитель по ссылке на песню | публичные эндпоинты, без ключа; сама песня не скачивается |

## AI-инструменты

| Что | Для чего |
|---|---|
| **Claude Design** (Anthropic) | 3D-модели мира: книга, лампа, кассетник, стол и комната (GLB) |
| **Claude** (Claude Code) | код приложения; 210 предметов-картинок библиотеки нарисованы Claude в SVG по правилам стиля, а не взяты из стоков |
| **Claude Haiku 5.5** во время работы приложения | сценарий каждого дня; новые предметы-картинки для слов, которых нет в библиотеке |
| ChatGPT (генерация картинок) | только концепт-макеты на этапе идеи; если попадают в презентацию, подписаны «концепт» |

## Шрифты, звук, музыка

| Что | Источник | Лицензия |
|---|---|---|
| Caveat (рукописный текст дня) | Google Fonts | SIL Open Font License 1.1 |
| Inter (мелкие подписи интерфейса, кириллица и казахские буквы) | Google Fonts | SIL Open Font License 1.1 |
| Звуки действий (шаги, искры, бумага) | синтезируются в браузере кодом (WebAudio), файлов нет | собственные |
| Песни демо-дней | присылает команда; источник и лицензия — вписать по каждой песне перед сдачей | вписать |

Чужих песен, чужих фото и ассетов без лицензии в репозитории нет. Фото демо-дней — собственные или с согласия.
