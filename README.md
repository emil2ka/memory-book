# Дневник-книга

Запись о дне + фото + песня → короткий фильм в книге-дневнике. Крошечный пиксельный человечек вытягивает со страниц собственные слова человека и превращает их в предметы, погоду и людей. Книга дня встаёт на полку.

REC GENESIS HACKATHON · кейс ArtTech · ноябрь 2026.

## Запуск

```bash
npm install
```

```bash
cp .env.example .env   # вписать ANTHROPIC_API_KEY (ключ остаётся на сервере)
```

```bash
npm run dev            # http://localhost:5183
```

Без ключа и без сети приложение тоже работает: день собирает запасной режиссёр на словаре.

Проверки:

```bash
npm test               # тесты хореографа, режиссёра, библиотеки предметов, хранилища
```

```bash
npx tsc --noEmit
```

## Как это устроено

```
текст + фото + песня
   → режиссёр (Claude Haiku 5.5, JSON по схеме; api/direct.ts)
   → проверка кодом (src/director/validate.ts: цитаты символ в символ, только известные id)
   → хореограф (src/timeline: детерминированный таймлайн 30–60 с, удары песни, полароид, облёт)
   → сцена (src/scene, three.js: реалистичный стол и книга, объёмный пиксельный человечек, наклейки-предметы)
```

- **Предметы** — 210 картинок-наклеек в SVG (`assets/kit2d`), нарисованы Claude по правилам стиля; поиск по словам ru/kk/en (`src/kit/library.ts`).
- **Дорисовка** — если слова нет в библиотеке, Claude Haiku 5.5 рисует новую картинку во время фильма (`api/make.ts`), код проверяет её (`src/kit/svg.ts`); не успела или не прошла — похожий предмет или кристалл.
- **Полка и хранилище** — дни лежат в браузере (IndexedDB), день можно скачать ZIP-папкой.
- **Песня** — темп файла измеряется по звуку; для ссылки — название через oEmbed и ручки «темп/энергия».

## Что работает

Полный путь: записать день → фото → песня → фильм → «Почему так» → полка → открыть снова → удалить. Палитра света, время суток и погода дня берутся из фото; противоречивые чувства показываются двумя состояниями в одном кадре. Русский, казахский и смешанный текст. Три демо-дня на полке сразу. Телефон — горизонтально (в портрете подсказка повернуть).

## Видео без записи экрана

```bash
npx tsx tools/make-video.ts --day 0 --photos 3 --song path/to/song.mp3 --out submission/video/day1.mp4
```

Сцена сама рисует каждый кадр фильма по таймлайну (`__dev.filmFrames`), ffmpeg склеивает кадры с песней.
