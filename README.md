# Дневник-книга

Запись о дне, фото и песня превращаются в короткий фильм в книге-дневнике. Крошечный пиксельный человечек проживает день заново. Он идёт от сценки к сценке, его слова становятся вещами, а книга рассказывает день под песню. Потом книга встаёт на полку.

**Сайт:** https://memory-book-mauve.vercel.app

**Трейлер (2:05, без голоса):** https://memory-book-mauve.vercel.app/trailer.mp4

## Запуск

```bash
npm install
```

Ключи — только в переменных окружения, в репозитории их нет:

- `.env` — `ANTHROPIC_API_KEY` (Claude API; остаётся на сервере);
- `.env.local` — `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (аккаунт и облако; без них дни хранятся только на устройстве).

```bash
npm run dev            # http://localhost:5183
```

Без ключа и без сети приложение тоже работает: день собирает запасной режиссёр на словаре.

База для облака: выполнить [supabase/schema.sql](supabase/schema.sql) в SQL-редакторе проекта Supabase. Схема создаёт таблицу `days`, приватное хранилище `photos` и правила RLS: каждый видит только своё.

Проверки:

```bash
npm test
```

```bash
npx tsc --noEmit
```

Сборка для Vercel (сайт и серверные функции `api/*`):

```bash
npm run build:vercel
```

## Что работает

- **Вход:** почта и пароль, или «без аккаунта». Выбор «мальчик / девочка» — кто ведёт дневник.
- **Запись:** до 3000 знаков на русском, казахском или вперемешку, 1–5 фото. Песня обязательна: одна из трёх, которые ИИ предложил под запись и фото, свой файл или ссылка.
- **Режиссёр** (Claude Haiku 5.5) выбирает 2–8 главных моментов дня и пишет к каждому строку рассказа. Строки в роде автора, без повторов и досочинённого: это проверяет код. На каждый момент — эмоция и действие человечка, всего 33 анимации. Момент-чувство играется анимацией, без предмета.
- **Фильм** длится 40–70 с:
  - человечек идёт от сценки к сценке;
  - сценка — главный предмет, место и второй человечек;
  - фото оживают сценкой своего момента;
  - склейки ложатся на доли песни, поворот дня — на её подъём;
  - финал «Поклон»: вещи и люди дня в ряд.
- **«Почему так»:** что взято из текста, из фото и как фильм подстроился под песню.
- **Полка:** дни на устройстве или в облаке (Supabase), пять демо-дней, экспорт дня ZIP-папкой.
- **Навигация по дням:** «Мои дни» — календарь месяца с корешками цвета настроения, поиск по названию и тексту, список. После фильма — бирки «прошлый / следующий день» и стрелки ← →.
- **Лимит:** 7 дней с ИИ в неделю на человека. Сверх лимита день собирается без ИИ: запасной режиссёр, сценки из библиотеки. Фильм всё равно получается.

## Как устроено

```
текст + фото + песня
   → карточки фото, 3 песни (Claude Haiku 5.5: api/photo.ts, api/song.ts)
   → режиссёр (Claude Haiku 5.5, JSON по схеме: api/direct.ts)
   → проверка кодом (src/director: цитаты символ в символ, рассказ, эмоции, повторы)
   → хореограф (src/timeline: детерминированный таймлайн под песню — доли, подъём, длина)
   → сцена (src/scene, three.js: реалистичный мир, объёмный пиксельный человечек, сценки из 3D-библиотеки)
```

## Чем сделано

three.js, React, Vite, TypeScript; Claude API (Claude Haiku 5.5); Supabase (Auth, Postgres, Storage, RLS); YouTube IFrame Player API; Vercel. 3D-модели мира — Claude Design; органика людей — Blender; бумажный интерфейс и иконки — ChatGPT. Подробно — в [submission/tools.md](submission/tools.md).
