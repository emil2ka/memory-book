# Дневник-книга — правила для агентов

Проект хакатона REC GENESIS / ArtTech. Дедлайн 22 ноября 2026, 23:59 по Астане. Начни с [00-HOME.md](00-HOME.md).

## Правила

1. **Концепция утверждена.** Книга, пиксельный человечек, слова превращаются в предметы, архив — полка. Не предлагать другую концепцию и не возвращаться к отвергнутым (список в 00-HOME).
2. **Работает важнее, чем задумано.** Не начинать следующий слой из [06-engine.md](06-engine.md), пока предыдущий не проходит целиком.
3. **Стиль — один.** Любая картинка и модель проходит правила [02-style-bible.md](02-style-bible.md). Преамбула из [prompts/STYLE_PREAMBLE.md](prompts/STYLE_PREAMBLE.md) вставляется в каждый запрос генерации без изменений.
4. **3D-модели — только через Claude Design**, один запрос за раз. Сначала пилот, потом остальное.
5. **Каталог закрыт.** Новый предмет, действие или эффект добавляется одновременно в ассеты, `catalog.json` и [05-director-llm.md](05-director-llm.md).
6. **LLM пишет сценарий, а не рисует.** Всё, что видно на экране, строит детерминированный код.
7. **Чужое не кладём:** ни песен, ни чужих фото, ни ассетов без CC0. Ключи — только в переменных окружения.
8. **После изменения статуса** обновить таблицу в 00-HOME и [04-asset-list.md](04-asset-list.md).
9. **Не пушить** в репозиторий команды без слова Эмиля.
